STRUKTUR FILE WEBSITE AGROMINA GROUP

1. index.html
   File utama website.
   Buka file ini di browser untuk melihat tampilan website.

2. style.css
   File desain website.
   Semua warna, layout, ukuran font, responsive mobile, dan desain kartu ada di sini.

3. script.js
   File interaksi sederhana.
   Berisi fungsi menu mobile dan efek header saat scroll.

4. assets/agromina-logo.png
   Logo perusahaan.
   Jika ingin mengganti logo, simpan logo baru dengan nama yang sama.

CARA MEMASUKKAN FOTO GUDANG, ARMADA, PRODUK
1. Masukkan foto ke folder assets.
   Contoh:
   assets/foto-gudang.jpg
   assets/foto-armada.jpg
   assets/foto-produk.jpg
   assets/foto-operasional.jpg

2. Buka index.html.
3. Cari bagian:
   <div class="photo-placeholder">
4. Ganti blok placeholder dengan:
   <img src="assets/foto-gudang.jpg" alt="Foto Gudang Agromina">

CATATAN
Website ini dibuat dalam bentuk HTML, CSS, dan JavaScript murni.
Tidak perlu instal React, Node.js, atau framework lain.
